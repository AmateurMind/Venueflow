# VenueFlow: The Smart Stadium Companion

**VenueFlow** is a premium, real-time event experience enhancer designed for large-scale sporting venues. Built for the **Prompt Wars** challenge, it addresses challenges in crowd movement, facility coordination, and attendee navigation.

## 🏆 The Problem Statement
> *Design a solution that improves the physical event experience for attendees at large-scale sporting venues. The system should address challenges such as crowd movement, waiting times, and real-time coordination.*

## 🚀 Key Features
- **Live Crowd Map**: Visualization of crowd density zones to help attendees move *smarter*.
- **Concession Efficiency**: Predictive wait times for food and facilities.
- **Coach Gemini**: An AI-powered concierge that uses logical decision-making to recommend paths and stalls based on current venue data.
- **Responsive Mastery**: Designed for both desktop dashboards and mobile hand-held navigation.

## 🧠 Logic & Innovation
- **Context-Aware Recommendations**: The system doesn't just show data; it makes decisions. Example: "Move to Gate 4 because it is currently operating at 40% capacity."
- **Premium Aesthetics**: Utilizing a sophisticated palette (#c3929a, #dfc188, #4c9574, #285451, #1d2d33) and elegant typography (**Instrument Serif** and **Barlow**).
- **Vibe Coding**: Built with an intent-first approach using Google Antigravity.

## 🛠️ Tech Stack
- **Framework**: Next.js (App Router, TypeScript).
- **Styling**: TailwindCSS + shadcn/ui.
- **AI Core**: Google Gemini (via simulated Next.js API routes).
- **Animations**: Framer Motion for a premium, alive feel.

## 📝 Assumptions
- Real-time density data is provided via venue-integrated sensors (simulated for the demo).
- Attendees have a persistent internet connection for Gemini interactions.
